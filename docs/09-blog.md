# Blog

Una entrada = un archivo `contenido/es/blog/<slug>.md` con esta cabecera:

```
---
titulo: Título de la entrada
fecha: 2027-03-15
descripcion: Resumen de una o dos frases (máx. 155 caracteres).
imagen: nombre-de-la-foto   # opcional, sin extensión, en public/img
publicar: true              # false = borrador
---
Texto en Markdown…
```

Los archivos que empiezan por `_` no se publican.
